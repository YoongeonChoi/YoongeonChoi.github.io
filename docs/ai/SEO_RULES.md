# SEO Rules

## Titles
- concise
- unique per locale
- avoid localized fallback reuse

## Metadata
- every public page gets canonical
- translated pairs get alternates only when both published
- noindex for preview/admin/incomplete translation

## Headings
- single H1
- meaningful H2 hierarchy

## Internal Linking
- article should link to related project when relevant
- retired content should point to replacement

## Structured Data
- ProfilePage on home/about
- Article on writing detail
- Breadcrumb on hierarchical pages
