# Design Bible

## Direction
- restrained brutalism
- modern, clean, not generic SaaS
- strong type, clear blocks, hard edges, wide whitespace

## Tokens
- spacing: `4, 8, 12, 16, 24, 32, 48, 64, 96`
- type: `14, 16, 18, 24, 32, 48, 64, 88`
- radius: `0` default, `8` max exception
- border: `1px` default, `2px` emphasis
- shadow: hard-edge single style only

## Accessibility Acceptance
- visible focus
- focus not obscured
- skip link
- keyboard-only admin
- modal escape
- form error announce
- reduced motion support

## Avoid
- glassmorphism
- generic dashboard cards
- meaningless gradients
- decorative 3D
- over-animated transitions
